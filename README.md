# CUA Task Examples

## About

This repository contains sample computer-use-agent (CUA) task scenarios designed to demonstrate skills relevant to computer-use and AI training workflows.

## Sample Task 1: Web Navigation

### Objective
Navigate to a specified website and locate a particular piece of information.

### Expected Actions
1. Open the web browser.
2. Navigate to the requested website.
3. Locate the required information.
4. Verify that the information matches the task instructions.
5. Record the result.

### Evaluation Criteria
- Correct website
- Correct information
- Accurate task completion
- Follows instructions
- No unnecessary actions

## Sample Task 2: Form Interaction

### Objective
Complete a simple online form using information provided in the task.

### Expected Actions
1. Open the form.
2. Enter the provided information in the correct fields.
3. Review the entries for accuracy.
4. Submit the form if instructed.

### Evaluation Criteria
- Correct field selection
- Accurate information entry
- Follows task instructions
- No missing required fields

## Skills Demonstrated

- Computer-use task execution
- Following multi-step instructions
- Web navigation
- Interface element identification
- Attention to detail
- Task verification
- Data quality awareness

## Disclaimer

These are portfolio examples created to demonstrate familiarity with CUA-style tasks. They are not presented as work completed for a specific company or client.
